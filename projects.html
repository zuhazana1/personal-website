Consulting (FBLA / DECA) Data science

FitHub is a peer-to-peer marketplace that lets people buy and sell clothing with each other. Our team of five built it with Python, Flask, Streamlit, and MySQL. I designed the database schema and the API layer, which let users search listings by size, category, and style preferences at the same time. See the code on GitHub or watch the demo.

Kalshi. We started a project called Project Future, which analyzed Kalshi’s current business strategies. We also ran a multi-step marketing campaign and a widget competition for them. Read the full report (PDF).

Manu Real Estate Report is an analysis of Manu Real Estate’s current operating strategies. We looked at how the company runs today and helped identify areas where it could grow within its existing operations. The findings and recommendations are laid out in the full report. Read the full report (PDF).

Stock Data Pipeline is an interactive dashboard that tracks 10 major stocks, including Apple, NVIDIA, Tesla, and JPMorgan, using data pulled from Alpha Vantage and FRED. We built it for DS 3500 with four views: an overview that compares how every stock performed from the same starting point, a drill-down with candlestick prices, trading volume, and sentiment for one stock at a time, an animated risk vs. return chart, and a rolling volatility chart. Users can filter by date range, ticker, and trading volume, or change the volatility window to see how risk shifts over time. See the code on GitHub.
